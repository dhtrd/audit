# منظومة ماي أودت — أداة مساعدة لدورة المراجعة
## My Audit — Audit Working Tool (Browser + Local Server)

> ملاحظة مهنية: هذه **أداة مساعدة توثيقية** تعمل في المتصفح مع خادم Python محلي بسيط.
> هي ليست منصة معتمدة رسمياً، ولا تُغني عن حكم المراجع وأداء إجراءات المراجعة وجمع أدلة
> الإثبات الكافية والمناسبة وفق معايير ISA / SOCPA / ISQM. كل المخرجات (قوائم، إيضاحات،
> رأي، عينات) هي **مسودات/قوالب** تحتاج مراجعة واعتماد المراجع المسؤول.

---

## 📌 نظرة عامة (الوصف الواقعي)
- **البنية الفعلية:** كل الحسابات والمعالجة تجري داخل المتصفح (JavaScript). ملف `standalone.py`
  هو خادم يقدّم الصفحة فقط (يشمل مسار `/api/upload/gl` لتحليل CSV على الخادم كخيار احتياطي،
  لكنه غير مستخدَم من الواجهة حالياً).
- **الاعتماديات:** يحتاج اتصال إنترنت لتحميل مكتبة قراءة Excel (`SheetJS` من CDN) وخطوط
  Google. بدون إنترنت تتعطّل قراءة Excel.
- **التخزين:** الحفظ التلقائي يتم في **IndexedDB داخل متصفحك فقط** (ليس سحابياً، ولا يُشارك
  بين الأجهزة، ويُفقد بمسح بيانات المتصفح). يُخزَّن عميل واحد نشط في كل مرة.

---

## 🚀 الوحدات المتاحة
1. **ميزان المراجعة**: رفع Excel/CSV. ملفات CSV تُقرأ بالتجزئة داخل المتصفح؛ ملفات Excel
   تُقرأ بالكامل في ذاكرة المتصفح عبر SheetJS (قد يبطؤ مع الملفات الكبيرة جداً/مئات آلاف الصفوف).
2. **قيود التسوية (AJE/RJE)**: تسجيل قيود متوازنة (يتحقق النظام من تساوي المدين والدائن) مع
   حساب الأثر على الأرباح والأصول والميزان المعدّل. *(الوحدة الأكثر اكتمالاً.)*
3. **لوحة المؤشرات ومراحل المراجعة.**
4. **الأهمية النسبية وتقييم المخاطر (ISA 320/315)**: تُحتسب من الأرقام الفعلية المرفوعة.
   عند وضع الخسارة يتحوّل الأساس تلقائياً إلى الإيرادات مع تنبيه (لا يتم اختراع رقم ربح).
5. **أوراق العمل والأدلة**: تسجيل مستندات الإثبات **محلياً** مع احتساب **بصمة SHA-256 حقيقية**
   للتحقق من السلامة. ⚠️ لا يوجد تشفير AES ولا تخزين سحابي — الملفات لا تُرفع إلى أي خادم.
6. **العينات (ISA 530)**: يولّد **خطة عينة** (الحجم وفاصل العينة) بصفوف فارغة يملؤها المراجع
   من دفتر الأستاذ. ⚠️ لا يولّد بنود عينة أو مبالغ وهمية، ولا يكتب استنتاج "بلا استثناءات"
   تلقائياً — التنفيذ والاستنتاج مسؤولية المراجع.
7. **مؤشرات الاحتيال (ISA 240)**: كشف مبدئي للمبالغ الدائرية الكبيرة.
8. **الزكاة وضريبة الدخل**: **نموذج تقريبي إرشادي فقط** — لا يطابق قواعد الوعاء الزكوي التفصيلية
   لهيئة ZATCA ولا يصلح للإقرار الرسمي.
9. **القوائم المالية والإيضاحات وتقرير المراجع (SOCPA/ISA 700)**:
   - قائمتا المركز المالي والدخل تُولَّدان ديناميكياً من ميزان المراجعة المرفوع.
   - يُحدَّث **11 إيضاحاً** من الـ22 ديناميكياً (1، 5، 6، 7، 9، 10، 14، 15، 16، 17، 22)؛
     الباقي نص إرشادي ثابت يحتاج تعبئة يدوية.
   - **تقرير المراجع يُولَّد كـ«مسودة قالب»** مع خانة يحدّد فيها المراجع نوع الرأي — ولا يصدر
     رأياً نظيفاً تلقائياً.

> **زر "تحميل ملف Word":** يشير إلى ملف خارجي ثابت على Google Drive، وليس ملفاً مولّداً من
> بيانات عميلك. استخدم زر الطباعة/التصدير للحصول على مخرجات من بياناتك الفعلية.

## 🔐 المصادقة والتنبيهات الأمنية
- **مصادقة HTTP Basic مدمجة** تُفعّل بضبط متغيّري البيئة معاً:
  ```bash
  export MY_AUDIT_USER=اسم_المستخدم
  export MY_AUDIT_PASS=كلمة_مرور_قوية
  python standalone.py
  ```
  عند تفعيلها تتطلب كل الطلبات اعتماداً صحيحاً (المقارنة بزمن ثابت لمنع هجمات التوقيت)،
  باستثناء `/health` الذي يبقى مفتوحاً لفحوصات موازِن الأحمال.
- إن لم تُضبط المتغيّرات فالمصادقة **معطّلة** ويطبع الخادم تحذيراً — عندها استخدمه محلياً فقط.
- ⚠️ Basic Auth بلا تشفير يرسل الاعتماد بنص شبه صريح؛ **استخدمه دائماً خلف HTTPS**
  (مثل Reverse proxy أو TLS على منصة النشر).
- الخادم متعدّد الخيوط (`ThreadingHTTPServer`) وبه **سقف لحجم الرفع** (افتراضياً 100MB،
  عبر المتغيّر `MY_AUDIT_MAX_UPLOAD`) لتقليل مخاطر استنزاف الذاكرة.

## 💻 التشغيل محلياً
```bash
python standalone.py            # أو: python run.py
```
ثم افتح: `http://localhost:8000`

## ☁️ النشر على Render
- أمر التشغيل: `python standalone.py`
- الخادم يقرأ المنفذ من المتغيّر `PORT` تلقائياً (متوافق مع Render ومنصات PaaS).
- **اضبط `MY_AUDIT_USER` و`MY_AUDIT_PASS`** في متغيّرات البيئة لتفعيل المصادقة قبل أي نشر عام،
  وتأكّد أن المنصة تقدّم HTTPS.

## ⚠️ حدود الاستخدام
هذه الأداة تساعد في التنظيم والعرض والتوثيق الأولي، لكنها **لا تنفّذ مراجعة** ولا تصدر رأياً
معتمداً. جميع الأرقام والاستنتاجات تخضع لفحص المراجع وحكمه المهني ومسؤوليته الكاملة.
